# 📊 Análise de Dados de Recursos Humanos com PySpark

## 📌 Sobre o projeto

Este projeto apresenta uma análise exploratória de uma base de Recursos Humanos utilizando **PySpark**.

O objetivo foi aplicar filtros, agrupamentos e transformações em DataFrames para investigar características dos funcionários e fatores relacionados ao ambiente de trabalho, remuneração e desligamentos.

## 🛠️ Tecnologias utilizadas

- Python
- PySpark
- Spark SQL
- Pandas
- Google Colab
- Jupyter Notebook

## 📂 Base de dados

A base contém informações profissionais e demográficas dos funcionários, incluindo:

- idade;
- departamento;
- cargo;
- gênero;
- renda mensal;
- salário;
- satisfação com o trabalho;
- horas extras;
- viagens de negócios;
- tempo de empresa;
- promoções;
- equilíbrio entre vida pessoal e trabalho;
- ocorrência de demissão.

## 🔎 Etapas desenvolvidas

- Instalação e configuração do PySpark
- Criação de uma SparkSession
- Importação da base em formato CSV
- Leitura dos dados com inferência de esquema
- Exploração das colunas e registros
- Aplicação de filtros
- Criação de agrupamentos
- Ordenação dos resultados
- Análise da distribuição dos funcionários por departamento
- Preparação de tabelas para conversão em Pandas

## 📊 Exemplo de resultado

A análise da quantidade de funcionários por departamento identificou:

| Departamento | Funcionários |
|---|---:|
| Pesquisa e Desenvolvimento | 961 |
| Vendas | 446 |
| Recursos Humanos | 63 |
